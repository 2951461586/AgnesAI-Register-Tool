# docs/ 索引

本目录装两类东西，**性质完全不同，别混着看**：

- **现行文档** —— 会被持续更新，改代码前该读的就是它们。**当前目录里只有这一类**。
- **带日期的历史留档**（`*-YYYY-MM-DD.md`）—— 冻结，只作证据。**当前一份都没有**；
  这是**约定**：真需要冻结一份证据时（如某次推翻前提的实测）才用这个命名。

## 现行文档

| 文件 | 讲什么 | 什么时候看 |
| --- | --- | --- |
| [`protocol.md`](protocol.md) | **协议核心**：6 步链路 / 端点与响应形状（含 **2026-10-15 起的 captcha 门**，§2②） / **限流实测与未测** / 出口为什么是吞吐杠杆 / CF Worker 邮箱的坑 / 判据表 | 动注册·登录·建 key·限流相关代码之前 |
| [`security-conventions.md`](security-conventions.md) | **公开仓库的安全与脱敏规范**：什么能进仓库、不能的放哪、终端输出怎么打码 | 任何要往仓库写配置 / 凭据 / 路径 / 主机标识的时候 |

## 约定

1. **不带日期**的文件是现行文档；带日期的（`*-YYYY-MM-DD.md`）是冻结留档，不再更新。
2. **新增协议 / 实测结论请进 `protocol.md`**，不要写回 README —— README 只留
   「怎么用 + 架构 + 已知限制」。同一份知识写在两处必然漂移，且漂移方向不可预测。
3. 所有文档遵守 [`security-conventions.md`](security-conventions.md) 的占位符约定：
   不含真实凭据 / 出口 IP / 实例子域 / 本机绝对路径。
4. **格式由 `markdownlint` 兜底**：配置是仓库根的 `.markdownlint.jsonc`，跑法是
   `npx --yes markdownlint-cli2 "README.md" "docs/*.md"`。标准是**项目符号统一
   `-`** + **不卡行宽**（中文长句与数据表折行更难读），理由写在配置的注释里。
   ⚠ 它**不在** CI 的四道闸门（pytest / ruff / pyright / gitleaks）里 —— CI 保持
   零网络依赖，文档 lint 由人手动跑。
